# COMP0124: Multi-Agent Artificial Intelligence

This repository contains materials and assignments for COMP0124 Multi-Agent Artificial Intelligence. 

## Repository Structure

### `lecture-notes-official`
This folder contains official lecture notes covering multi-agent decision-making concepts.

#### Contents:
- `lemke-howson-algo-note.pdf`: Explanation of the Lemke-Howson algorithm for computing Nash equilibria.
- `week1-intro-to-game-theory.pdf`: Introduction to game theory for AI.
- `week2-potential-games-and-bargaining.pdf`: Potential games and cooperative strategies.
- `week3-repeated-game.pdf`: Analysis of repeated game dynamics.
- `week4-computation-of-nash-equilibria.pdf`: Computational methods for Nash equilibria.
- `week5a-strategic-patrolling.pdf`: AI-driven strategic patrolling techniques.
- `week5b-lemke-howson-algorithm.pdf`: Detailed notes on Nash equilibria computation.

### `computer-practicals`
This folder contains Jupyter notebooks for practical implementations of multi-agent AI concepts.

#### Contents:
- `MAAI-lab1-game-theory.ipynb`: Game theory fundamentals and equilibrium strategies.
- `MAAI-lab2.ipynb`: Implementation of strategic decision-making in multi-agent settings.
- `MAAI-lab3-repeated-games.ipynb`: Repeated game scenarios and cooperation strategies.
- `MAAI-lab4-nash-equilibria.ipynb`: Computation of Nash equilibria in various settings.
