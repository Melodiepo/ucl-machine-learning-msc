# COMP0197: Applied Deep Learning

This repository contains materials, assignments, and notes for COMP0197 Applied Deep Learning. 

## Repository Structure

### `coursework-individual`
This folder contains coursework assignments focused on logistic binary regression and extreme learning machines.

#### Contents:
- `comp0197-cw-individual-question.pdf`: Coursework assignment brief.

### `lecture-notes-official`
This folder contains official lecture materials covering core deep learning concepts.

#### Contents:
- `week1-ml-basics.pdf`, `week2-ml-basics-2.pdf`, `week2-ml-basics-3.pdf`: Introduction to machine learning fundamentals.
- `week3-feed-forward-nns.pdf`: Feedforward neural networks and training process.
- `week3-training.pdf`: Optimization techniques, loss functions, and backpropagation.
- `week4-cnn.pdf`: Convolutional Neural Networks (CNNs).
- `week4-regularisation.pdf`: Regularization methods such as dropout and weight decay.
- `week5-sequence.pdf`: Sequence modeling with Recurrent Neural Networks (RNNs) and LSTMs.
- `week6-evaluate.pdf`: Model evaluation techniques including precision-recall and confusion matrices.
