# COMP0168: Machine Learning Seminar

This repository contains materials and tutorial notebooks for COMP0168 Machine Learning Seminar. 

## Repository Structure

### `lecture-notes-mine`
#### Contents:
- `comp0168-lec-notes-melodie-v1.pdf`: Personal lecture notes on the topics covered in the course.

### `lecture-notes-official`
#### Contents:
- `wk1-gaussian-processes.pdf`: Introduction to Gaussian Processes for regression.
- `wk2-bayesian-optimization.pdf`: Bayesian optimization methods for efficient learning.
- `wk3-numerical-integration.pdf`: Advanced numerical integration techniques in ML.
- `wk4-message-passing.pdf`: Message passing algorithms for Graph Neural Network.
- `wk5-meta-learning.pdf`: Meta-learning strategies for few-shot learning.

### `tutorial-notebooks`
#### Contents:
- `message-passing-tutorial/`: Subfolder with message passing implementation.
- `bayesian-optimization-tutorial.ipynb`: Practical implementation of Bayesian optimization.
- `gaussian-process-tutorial.ipynb`: Gaussian Process regression tutorial.
- `prototypical-network-tutorial.ipynb`: Prototypical network implementation for few-shot learning.

### `comp0168-group-pre-paper.pdf`
Group pre-review of a Multi-view Bayesian Optimization Dimensionality Reduction paper in Engineering Design.

### `comp0168-individual-paper-review.pdf`
Individual paper review on E(n) Equivariant Graph Neural Networks (EGNNs), a new class of GNNs that remain equivariant under the Euclidean group E(n), i.e. translations, rotations, reflections, and permutations of nodes in an n-dimensional space.
